## 外部贡献审查要点

- **#18 是真实的授权边界漏洞**：`scope` 尾部通配原为前缀匹配，`app.example.com*` 会命中
  `app.example.com.attacker.com`（越权子域后缀欺骗）。修复改为**点标签边界**匹配
  （自身或左侧展开的子域），裸 `*` fail-closed，八位组通配明确改为 CIDR。
  审查动作：工作树跑该分支测试（69/69）→ 5 个边界样本复核（含 2 个攻击样本）→ rebase → 合并。
- **#20** 的修复本身正确（`node --test test/` 在 Node 22 会被当模块路径报错），
  但当前 README 已在 PR14 重写中改为 `node --test`；核实全仓无残留后按「已解决」关闭并说明。
