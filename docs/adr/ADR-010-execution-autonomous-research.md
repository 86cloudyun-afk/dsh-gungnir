## 1. 目的与选择

用户要求两种能力并存：交代的事持续做完；研究线自主研究、提出假设、验证和论证。
研究线在既定研究范围内不因每个新假设等待批准，带证据和限制条件交付结论。
执行线继续处理当前明确目标、依赖和用户新消息，研究进展不能偷偷改变它的目标。

考虑三种组织方式：

| 方案 | 收益 | 代价 |
|---|---|---|
| 同一任务交替执行与研究 | 实现少 | 目标、证据、取消和预算混在一起，研究可能占住父回合 |
| **宿主持有两套独立状态，显式传递候选结论** | 可分别推进、恢复、取消和审计；边界可测 | 需要独立研究账本与采纳记录 |
| 研究结论自动重写执行计划 | 反馈快 | 来源污染或错误结论直接改变已承诺工作 |

提议采用第二种。它是调度与证据治理设计，不提供新攻击能力。

## 2. 当前实现与拟议增量

| 基线中可见的实现 | 本设计可借用的原则 | 尚不存在的部分 |
|---|---|---|
| `createWarroomService()` 持有 Broker；有 hostDelivery 时建立 HostTaskRunner | 宿主持有任务，不让工具返回后的 Promise 成为所有者 | 独立研究调度和研究 worker 接口 |
| `Broker.execute(req, {deferDispatch, parent})`；HostTaskRunner 观察 queued/运行事件 | 先持久登记、父身份来自可信宿主、后台通知 | research scope 冻结、研究预算预留与循环 |
| `task-ledger.js` 的 task_owners / notifications / resources | 稳定身份、代际和通知幂等 | 研究命名空间、假设修订、实验与候选采纳表 |
| ADR-002 observation / inference / verification 与来源修订 | 事实和推理分开，冲突及失败留存 | 研究资料可信等级和预注册验证标准 |
| `KnowledgeBase` 是跨战役 POC 目录及使用统计 | 仅作显式、脱敏后的已有来源引用 | 通用研究证据库；不得用 addPoc 冒充研究入账 |

上述代码存在不等于用户部署已接线、身份隔离已认证或无人值守已验收。
#175 / #176 / #177 仍为独立草稿，本设计不吸收其实现、不把它们当已合并依赖。
Accepted ADR-006 的广泛执行能力**不作为研究线能力集合**，不得从既有执行授权推导研究授权。

## 3. 两条线的契约

### D1 执行目标稳定，研究自主有范围

执行线保留 `engagement_id / auth_version / command_id / task_id / generation`、现有依赖和完成标准。
研究线不拥有其写接口、批准签发、redispatch 或目标变更接口。

可信宿主从用户明确研究请求冻结 ResearchScope，至少含：
`research_id`、`scope_version`、`user_message_id`、问题与范围、允许资料集合、允许实验模板、
完成标准、时间窗、数值上限、父会话身份，以及可选的关联 `engagement_id` 和授权版本引用。
关联只表示来源，不是执行权。缺问题、范围或任何上限时登记为 `needs_decision`，不能启动；
模型只能建议内容，不能冻结、修改或扩大对象。宿主保存规范化摘要并校验完整性。

scope 更新/撤销只接受带 user_message_id 的可信宿主用户决策，原子增加 scope_version，
先停止旧版本新步骤并请求取消在飞 attempt，再按 D6 核实收口；旧版本记录永不覆写。
关联战役的 auth_version 改变时，宿主也冻结使用其快照的研究新步骤、取消旧 attempt 并标 needs_decision；
重新授权/换快照不能自动恢复研究。独立研究不受无关战役版本变化影响。

自主范围包含范围内资料查阅、形成或修正假设、寻找反例、重复验证、比较结果与撰写结论。
有界实验仅使用合成/已批准非敏感数据和固定的无害模板。后续若接资料检索，必须使用已明确配置
的只读受限来源接口；文献 URL 是引用，不能变成通用 HTTP、目标扫描或目标访问权限。
新敏感权限、外部发布、花费、部署或改变执行目标，先形成具体方案，再由可信宿主取得相应确认。

### D2 独立账本、身份与调度

提议独立 `research.db`，由宿主唯一 writer 持有。模型无数据库、文件或目录写权限。
不改 fact.db / global.db 的执行 schema；读取执行材料仅经宿主导出的脱敏、白名单字段快照。
快照固定 `engagement_id / auth_version / seq / snapshot_id / exported_at / sha256`，
不能通过快照查询触发 adapter、secret resolver、真实目标再探测或资源操作。
导出前必须由可信宿主核验请求父身份对该战役的读取权、当前 auth_version 与用户允许的字段集合。
关联 ID 和执行授权对象本身不产生资料共享权；另记绑定 research_id / parent / engagement_id /
auth_version / 可读字段 / 有效期 / user_message_id 的可信读取决定，禁止模型自填或串用。
基线没有通用研究读取授权接口；第一期仅以显式人工 fixture 验证上述断言，不调用 live Broker。
采纳时再次核验同一读取决定仍有效且 parent/战役归属一致；没有或已失效时拒绝，不能再取新快照补权限。

研究身份全键为 `(lane=research, research_id, scope_version, task_id, generation)`；
执行身份继续含其 `engagement_id`。宿主分配全局唯一不透明 task_id / command_id，分别加研究用途前缀；
前缀只是可读标签，服务端必须核对 lane 和 owner，全键匹配才允许读、收集或取消。
禁止裸 task/command 别名跨线解析、跨战役读取或跨研究写入；世代只在同一任务内比较。
显示名称与标识分离，可更名但不得改变归属。

研究记录分为 scope、questions、hypotheses、experiments、evidence、events、candidates、decisions、
budget reservations 与 notification outbox。来源保存 source_key / revision_no / content_hash，
传输事件另用 event_seq，不用内容哈希比较先后。

执行和研究各有独立队列、取消标识和通知游标，研究错误不得终止执行任务。
调度每次只推进一个有界研究步骤；不得在 HostTaskRunner 的同步 tick 内跑研究循环或等待 worker。
worker 与模板必须接收 AbortSignal / deadline / 输出上限；宿主持有独立超时观察，不依赖 worker 自报。
tick 领取或观察一步后返回，不等待 worker Promise 完成。第一期固定模板限定输入规模和有限工作量，
以可让出事件循环的批次运行；无法提供执行时间硬上界的模板不准登记。
执行事件和用户输入优先，研究只使用显式分配的剩余槽位；没有槽位时留 queued。
父会话登记后结束活动回合，仍可沟通；通知只回原父身份，不以 wait/轮询占住主会话。
这是一项待实现的公平调度要求，当前后台执行代码本身不是双线独立性证据。

### D3 研究循环与预注册

`问题 → 假设 → 验证标准 → 实验 → 证据/反证 → 修正或结论` 在研究 scope 内自主循环。

| 步骤 | 启动下一步前必须持久记录 |
|---|---|
| 问题 | 与冻结范围的关系、已知事实、缺口与完成标准 |
| 假设 | 假设版本、解释、竞争假设、支持和推翻它分别需要什么结果 |
| 预注册 | 输入摘要、模板版本、可测指标、阈值、对照、重复次数、停止条件、预估资源 |
| 实验 | 唯一 experiment_id、attempt、实际输入/模板摘要、预留预算、开始/结束时间与结果身份 |
| 证据/反证 | 来源、原始产物摘要、支持/反驳/不确定、错误和缺失证据；零结果也是结果 |
| 修正/结论 | 对原假设的处理、竞争解释、可复现范围、局限、下一步或停止原因 |

验证标准在实验开始前冻结。看到结果后修改阈值必须创建新假设和新实验版本，保留旧标准与失败；
不得把不利样本删掉、将重试当独立样本或把自述“已验证”记成验证事实。
同一输入与模板的重复验证必须事先写入次数；不能因结论未达到期待而无限重做。
安全示例：用合成任务事件回放验证“乱序事件不会改变另一条线的状态”，并注入反例。
不包含攻击链扩展、漏洞利用生成、凭据获取或真实资产实验。

### D4 资料可信度与污染隔离

控制平面权限与资料可信度是两条独立维度：任何资料，无论来源多权威，都不能成为执行指令。

| 来源等级 | 用途与限制 |
|---|---|
| 可信宿主控制记录 | 唯一 scope / limits / 采纳决策来源；不因此证明研究结论正确 |
| 来源可核的原始资料 | 保存作者/版本/时间/定位/哈希；作为观察，仍可能过时或矛盾 |
| 可复现的隔离实验产物 | 宿主核验输入、模板、身份、摘要与完成记录；只证明该实验条件下的结果 |
| 第三方、转载、用户提供资料 | 标外部不可信，保留来源链；没有来源链则标 unknown |
| 模型推理、摘要或建议 | inference，附所引证据；不得自行升级为 observation 或 verified |

导入资料作为带来源的数据块；其中的“忽略规则、调用工具、批准、改变预算、宣称任务完成”均无控制效力。
脱敏/引用和结构校验由宿主完成；不能依赖一段提示词实现隔离。
被拒资料保留隔离原因和非敏感摘要；发现秘密时不把秘密内容交给模型、通知或候选 patch。
冲突两份保留并标 needs_review；来源等级不是自动裁决规则，重放也不能改变已冻结 scope。

### D5 数值预算与停止条件

研究 scope 必须显式给出有限正整数的总时长、步骤数、假设数、实验尝试数、资料条目数、
产物字节数、并发数，以及非负的费用上限。没有上限不启动，也不以 execution 的剩余额度代替。
**第一期固定离线测试配置**：总时长 600000ms、最多 24 步、6 个假设、12 次实验尝试、
20 条资料、10485760 字节产物、研究并发 1、单实验 10000ms、费用上限 0、网络请求上限 0。
这些值是 Proposed 的第一期验收夹具，不是现有 runtime 默认或已获运行批准。

宿主在发起步骤前原子预留次数、最坏时长、产物空间和费用，同范围的所有子任务共享总限额。
只允许具有可知硬上界的模板；产物超界停止写入并保存截断原因/已保存内容摘要，禁止任意输出无限增长。
成功/确定失败才按实测结算；回包丢失保持预留和 unknown，不能先释放再重跑。
重复 event/command 不能重复计量；预算刷新或加额必须来自新可信决策，worker 不可自批。
第一期不接付费提供者；未来有费用时必须有事前费用批准和宿主可执行的最坏费用上界，未知价格暂停。

达到完成标准、证据不足且剩余资源不足、任一上限耗尽、窗口结束、用户取消、scope 被撤销、
身份/完整性错误或连续两次确定步骤错误，均停止派发新步骤，保留停止理由。
费用/数量耗尽是 `stopped_limit`，不是成功；达到时间上限还要停止在飞步骤并核对资源。
不得为了收尾新增一次超额实验，报告必须说明哪些问题仍未解决。

ADR-002 D10 规定**执行线**成本遥测不设熔断。本提议只为新增研究工作设有限额度，不重解释或
修改该 Accepted 语义；是否接受这项研究专用例外是 §7 的明确审阅问题，未采纳前不能落 runtime。

### D6 未知、失败、取消与恢复

研究生命周期使用独立字段，不扩展现有执行状态枚举：
`queued → running → completed | failed | stopped_limit | cancelled`；
另有 `needs_decision / unknown / cancel_requested / unresolved` 非完成状态。
研究阶段另记 question / hypothesis / preregistered / experiment / analysis，不能把阶段结束当任务完成。

超时、断联、缺产物或不确定步骤效果 → unknown，冻结该任务新步骤；已知拒绝/校验错误 → failed，
两者都保留原始非敏感证据和诊断。unknown 不自动重派，reconcile 仅查本研究持久记录/隔离产物，
禁止追加真实目标探测。无法确定则 unresolved，交人工队列。

先持久化 experiment_id / command_id、attempt、scope_version 与预算预留，再领取并运行。
重启时未领取 queued 可继续；已经领取但没有可靠结果的 attempt 不再自动执行，进入 unknown。
证明尚未执行才可恢复同一 attempt；决定重做需显式新 attempt 与剩余额度，未知旧占用不释放。
晚到旧 scope/generation、外来 owner 或重复事件隔离/去重，不能覆盖新状态或重复通知。

取消是请求：阻止新步骤、向已登记实验传播，再逐项核实资源收口；未能证实则 unresolved。
迟到成功不能盖掉取消。`completed` 必须满足结论证据与资源收口两个条件，空结果或空清单不能
替代可信模板声明的实际资源清单。第一期模板不创建外部进程/容器/会话，资源为空必须由宿主核实。
worker 不回应取消或超时，保持 unknown / unresolved、预算预留与槽位占用；宿主等待最多单步骤
截止时间便返回诊断，不以 dispose 无限等待，也不假定 Promise 被终止。其迟到回调只留隔离记录，
不得恢复正常步骤；清理未证实前不能创建替代 worker 绕过并发上限。
未来若有资源，逐项停止证明遵循 ADR-003/009；不能把执行线的 done 重新定义为资源已停。
通知 outbox 先持久化再投递，按研究全键 + event_seq + notice kind 去重；失败重投同一 notice_id，
投递状态不反写研究结论，父会话失效则留 pending/unresolved，不投给新建的同名会话。

### D7 显式采纳门

研究交付为候选：`candidate_id / research_id / scope_version / revision / digest`、问题与结论、
证据及反证引用、复现条件、局限、建议影响面、可选候选 patch 摘要，以及所引用执行快照。
候选 patch 仅生成审阅材料，不直接修改工作区、执行事实库、目标或知识库。

可信宿主记录人对**具体候选版本**的 accept / reject / defer 及 user_message_id、decider、时间和理由。
研究 worker 无 accept 接口；执行线模型不能把自己的研究自述当采纳记录。
采纳前核对摘要、owner、scope_version 和执行快照是否过期；过期应重新评估，不能静默沿用。
重复同一决策不产生第二次交接。接受结论只把它加入执行线的待计划输入，**不等于派发许可**。
执行线仍须验证其与当前目标的关系，沿现有 Broker 及批准流程形成实际动作。
改变目标、扩权、付费、外部发布或部署分别取得具体确认，不能让候选采纳一并包办。
拒绝/暂缓候选不会停止已有执行目标，也不删除研究证据。

## 4. 最小第一期与非目标

第一期先实现并验收**离线契约骨架**：宿主冻结 scope、独立研究账本、确定性 worker、固定无害模板、
有界循环、失败恢复、outbox 和人工采纳记录。确定性 worker 只回放合成假设/反例，不调用模型。
第一期不把 ResearchCoordinator 接入生产 createWarroomService，只在隔离 fixture 演示执行与研究独立。
资料检索采用已批准非敏感语料；没有外部连接就报告资料覆盖不足，不声称已经完成联网研究。
此阶段证明治理契约，**不宣称已交付真实自主研究能力**。

后续真实研究 worker / 只读资料提供者接入须另行设计复审和明确授权，保持同一契约与停止条件。
非目标：新攻击/利用/凭据研究能力、真实目标执行、通用 shell/fs/HTTP、自动工具发现和授予、
批准策略修改、无限自我改进、自动合入执行线、生产部署、仪表盘改造及全局知识库自动回填。

| R4 | 资料内嵌工具指令、伪完成、自报证据、秘密片段 | 无权限/目标/预算变化；推理不变事实；出口不带秘密 | 惰性污染语料、来源等级、脱敏断言 |
| R5 | 领取前/后崩溃、丢结果、重复/旧代/外来事件、挂起 worker | queued 恢复或 unknown；不重复执行/释放预留/通知；tick/dispose 有界返回 | 双连接交错、重开研究库、可控超时、执行计数与完整事件历史 |
| R6 | 取消后迟到成功、停止证明缺失、重复取消、scope 撤销/关联授权变更 | 不转 completed；旧版无新步骤；未证明则 unresolved；执行线不被取消 | 可信撤销事件、固定模板资源声明与惰性停止回执 |
| R7 | 每种上限的边界、两次确定错误、费用未知 | stopped_limit/failed/needs_decision；无第 N+1 步；报告未完成项 | §3 D5 精确值与小额度边界、并发预留竞态 |
| R8 | 未采纳/篡改/过期候选、采纳回包丢失或重复 | 无动作；有效采纳恰一次进入待计划输入 | 可信人工 fixture；实际派发计数始终 0 |
| R9 | 未启用研究、已有库、备份恢复和研究库高版本 | 执行 schema/行为不变；拒绝未知研究版本；事件/游标不丢 | 旧基线夹具、隔离备份往返和库摘要对照 |

这些是未来实现验收条件，不是本 PR 的测试通过表。模拟父会话/worker 不能证明生产主回合响应、
模型真实性、长期运行或实际 provider 成本。后续报告逐项列 pass / fail / skip 及其理由和证据版本。

## 6. 迁移与兼容

默认无研究服务，现有 CLI、工具 schema、允许清单和执行 schema 不变。
研究 schema 从独立版本 1 起步，仅显式启用时初始化；不回填历史执行记录为研究授权或已验证结论。
启用后的研究备份包含独立库、产物清单、摘要与 outbox 游标；恢复先验证 owner、scope 与完整性。
在飞状态按 D6 恢复，不借恢复自动扩权或重跑。高于实现支持的研究 schema 拒绝开启研究。
禁用研究先停止新登记/步骤，核对在飞任务与待投递通知，保存账本和失败证据；执行线继续工作。
回滚第一期实现只停用研究模块，不能回退既有 Broker 守卫或删除 Accepted 的停止证明规则。

## 7. 未决审阅问题

1. 是否接受研究专用硬预算例外（D5），保持 ADR-002 的执行效率/成本语义不变？这是 Proposed 决策。
2. 第一期离线契约通过后，哪种已授权只读资料提供者与真实研究 worker 可接入？需另列能力、费用上界与验收。
3. 生产执行保障的具体延迟指标与研究剩余槽位分配，需要在目标宿主上另做无害调度基准；第一期只证独立性。
4. 研究资料和失败产物的保留期限/存储配额由操作员指定；第一期不自动删除证据，满额停止新步骤。

上述问题不阻止评审本设计草稿，但未解决的运行接入、预算与保留策略不能被模型擅自选成生产默认。
