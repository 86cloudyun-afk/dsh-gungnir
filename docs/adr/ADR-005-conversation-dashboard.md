# ADR-005 对话联动的只读战图

- 状态：Proposed
- 关联：ADR-002（事实库所有权）、ADR-004（UI 留到 v0.3）、[设计](../dashboard/design.md)

## Context

操作员已选择“全局总览 + 局部钻取”，并要求完整极简线路与对话定位同时保留。现有 CLI、报告和事实库仍然承担战役执行与权威记账。

## Decision

新增可独立运行的 `warroom-dashboard` 包：只读快照投影、无外部运行依赖的 SVG 战图和 DSH 原生页面适配。既有 Accepted ADR 不修改；本实现为 UI 范围的后续功能预览，不改变 v0.1/v0.2 的执行、权限和存储契约。

主界面提供完整分层图、总览/局部联动、对话定位及跳板旁注。导航输入仅查找和定位；有副作用的战役操作继续使用现有工具与门闸。

DSH 对话不可读、库为空或损坏时明确提示，禁止自动用演示掩盖真实接入失败。历史证明、当前有效性、租约和出口核验分别表达。

## Consequences

数据投影与布局独立测试，兼容既有 CLI 和宿主服务。静态页面和只读接口仍需按宿主的鉴权与作用域挂载；本地验证、公开接口契约验证和实际宿主验证分别留证。未来要增加执行控件必须另行定义授权与门闸接入。
